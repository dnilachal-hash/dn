HMC Fee Management System v1.0
================================
Homoeopathic Medical College & Hospital

WHAT WILL BE INSTALLED
----------------------
- Application files to Program Files\HMC-FeeManagement\
- All Python dependencies (bundled — no internet needed)
- React frontend (bundled)
- SQLite database (auto-created on first run)
- Windows Firewall rule for port 8001
- Desktop and Start Menu shortcuts

AFTER INSTALLATION
------------------
- Browser opens to http://localhost:8001 automatically
- Default credentials (force-change on first login):
    admin      / Admin@1234   (Super Administrator)
    accounts   / Accounts@1234 (Fee Clerk)
    principal  / Principal@1234 (View only)
    auditor    / Auditor@1234   (Audit only)

PRE-LOADED DATA
---------------
- 1 BHMS course with 5 batches
- 3 academic sessions (2023-24, 2024-25, 2025-26)
- 5 student categories
- 3 financial years (2025-26 active)
- 7 payment modes (Cash, Cheque, DD, UPI, Bank, Card, Other)
- 15 fee heads (Tuition, Exam, Hostel, Library, Lab, etc.)
- 1 sample fee structure
- 5 sample students with 3 sample receipts

SUPPORT
-------
For support, contact your IT administrator.
Data is stored in the installation folder as fee_management.db.
Back up this file regularly using the Backup module in the software.

LEGAL DISCLAIMER
----------------
All fee structures and amounts pre-loaded are sample data only.
Configure actual fee structures before live use.
